# Cryptex Rebuild

## 🎯 Project Scope
The next evolution of the Cryptex AI platform. This rebuild focuses on migrating from a monolithic script architecture to a modular, microservice-ready system using Node.js and Python.

## 🏗️ Architecture
- **Core Engine:** Python (FastAPI) for LLM orchestration.
- **Client Interface:** React (TypeScript) for a modern, responsive UI.
- **Infrastructure:** Dockerized deployment with Terraform orchestration.
