## OpenList (files.psidex.com)
- **Admin password:** `<CHANGE_ON_FIRST_LOGIN>`
- **Reset:** delete `data/openlist/data.db` and restart the container.

## Vaultwarden
- **Admin token:** generated by `scripts/gen-vaultwarden-token.sh`
- **Bootstrap user:** create via web UI on first launch.

## Forgejo
- **Admin user:** created on first launch via web UI.

## PocketID (OIDC)
- **Initial setup token:** printed in container logs on first boot.

## Cloudflare Tunnel
- **TUNNEL_TOKEN:** from CF dashboard → Zero Trust → Networks → Tunnels.

## Kopia (backups)
- **Repository password:** env var `KOPIA_PASSWORD` in `.env`.
- **B2 keys:** `B2_KEY_ID` / `B2_KEY` in `.env`.

## Backblaze B2
- **Bucket:** `cryptex-backups` (or per your CF/B2 setup).
- **Key:** generated in B2 dashboard; least-privilege per bucket.

## n8n
- **Encryption key:** `N8N_ENCRYPTION_KEY` in `.env`.

## Notes
- All passwords should be rotated on first deployment.
- Use `pwgen -s 32 1` or `openssl rand -base64 24` for new secrets.
