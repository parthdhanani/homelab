# /plan

1. **Understand** — current state, goal, constraints
2. **Options** — 2-3 approaches: what it is · complexity · tradeoff
3. **Recommend** — pick one, why, what's given up
4. **Steps** — numbered, phased if >5, success criteria per phase
5. **Risks**

| Risk | Severity | Detect | Rollback |
|------|----------|--------|----------|

Proportional to task. Suggest `/model` opus for architecture/infra. End infra plans with `/save`.
