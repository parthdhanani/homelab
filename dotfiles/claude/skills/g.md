# Gemini Query Skill

Run any research or question through Gemini CLI instantly.

**Usage:** `/g what is the fastest animal on earth`

This skill:
- Takes your query as input
- Runs it through the Gemini CLI
- Returns results directly

**Examples:**
- `/g research best VPN alternatives for battery life`
- `/g what are the latest React patterns 2026`
- `/g explain quantum computing in simple terms`

The query is sent directly to Gemini's research capabilities.
